# Technique icons (Sly 2)

The built-in icons of the Thievius Raccoonus techniques (Sly2-Release/techicons.h): `<key>.png` (256 x 256, straight
alpha) drawn from `<key>.svg`, embedded into Sly2-Release at build time. Original artwork made for SafeHouse.

Keys: `leaping_dragon`, `silent_sprint`, `rail_sprint`, `climbing_cobra`.

A PNG of the same name in the Mods folder's `Icons` subfolder (`Mods/Icons/leaping_dragon.png`) replaces the built-in
one: any square size up to 1024, with transparency where the icon is not.
